# 梦幻时空助手（MHTimeHelper）

梦幻时空助手是一款基于 AutoHotkey v2 的《梦幻西游》辅助工具，用于自动完成日常任务流程。本仓库面向测试用户开放，欢迎试用并通过 Issues 反馈问题。

## 功能用途

- 自动执行《梦幻西游》一次性多开，减少重复操作
- 支持时间同步与脚本调度（时间同步需配合第三方同步器，详见下方「关于同步器」）
- 基于 AutoHotkey v2 编写，脚本开放可查、可自行修改

## 运行方式

1. **源码运行**：安装 [AutoHotkey v2](https://www.autohotkey.com/v2/) 后，双击 `梦幻时空助手.ahk` 即可运行。
2. **可执行文件运行**：直接双击仓库中的 `梦幻时空助手.exe`（仅限 Windows），无需额外安装 AutoHotkey。
3. 运行前请确认游戏窗口状态符合脚本要求，运行后按脚本界面提示操作。

## 关于同步器

本仓库仅提供自研的梦幻时空助手主程序与源码，**不包含、也不再分发同步器程序**。

时间同步所需的同步器属于**第三方软件**，与本项目无关联，本仓库不对其来源、安全性及可用性作任何担保。如有需要，请自行通过可信渠道获取并自行评估使用风险。
