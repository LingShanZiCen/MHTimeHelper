# 幻夜工坊 Nightforge

梦幻西游多开与窗口管理小工具（C# / WPF，单文件绿色版，免安装）。

只做\*\*窗口层面\*\*的批量启动与排列管理，不涉及任何游戏内操作、内存修改或外挂功能。

## 功能

| 模块 | 功能 |
|---|---|
| 游戏设置 | 游戏路径、窗口标题关键词、启动数量（1–5）、启动后等待秒数 |
| 窗口布局 | 分辨率模式与自定义窗口宽高；5 个窗口五点布局（左上 / 上中 / 右上 / 左下 / 右下），其他数量自动网格排布 |
| 一键操作 | 一键启动多开、前置全部窗口、老板键（一键最小化）、获取窗口大小 |
| 全局热键 | 前置全部 / 老板键 / 获取窗口大小三组热键，支持直接输入或按键录制 |
| 同步器（可选） | 仅填写第三方同步器路径以便一键启动，本程序不包含同步器 |
| 运行日志 | 界面内查看，支持清空与导出为 txt |
| 托盘 | 关闭时可选最小化到托盘，托盘菜单可呼出主界面或退出 |
| 联网更新 | 启动时自动检查新版本，发现后弹窗提示并一键跳转下载 |

## 新版（C#）与老版（AHK）对比

老版本是用 AutoHotkey v2 写的脚本（仓库内存档的 `梦幻时空助手.ahk`），新版本是用 C# / WPF 重写的 `Nightforge`。两者功能范围一致（都只做窗口层面的事），差别主要在**易用性、稳定性和后续维护**上。

| 对比项 | 老版本（AutoHotkey） | 新版本（C# / WPF） |
|---|---|---|
| 安装与运行 | 脚本需要 AutoHotkey 运行环境，打包的 exe 依赖 AHK 运行时，部分安全软件可能拦截或误报 | 单文件 exe（约 67 MB），双击即用，免安装、无需另装运行时，被拦截误报的情况明显减少 |
| 界面 | AHK 自带 GUI，控件和样式比较简陋，高分屏下容易发虚 | WPF 界面，支持高 DPI 缩放，布局随窗口自适应，观感与操作都更接近正常软件 |
| 热键录制 | 录制能力较弱，遇到系统已占用的组合键容易录完不生效 | 窗口级按键捕获，冲突时给出提示并可改绑，录制完立即生效 |
| 窗口布局 | 排列方式固定、可调参数少 | 支持分辨率模式与自定义宽高；5 个窗口五点布局，其他数量自动网格排布 |
| 配置 | `config.ini` | 沿用 `config.ini`，老版配置放到新程序旁边即可直接迁移 |
| 更新 | 需要自己留意更新并手动下载覆盖 | 启动后自动联网检查，弹窗显示更新内容并一键跳转下载，可跳过指定版本 |
| 日志 | 文本日志，需要自己去翻文件 | 界面内直接查看，支持清空、导出为 txt |
| 托盘 | 基础托盘菜单 | 关闭窗口可选最小化到托盘，托盘菜单可呼出主界面或退出 |
| 稳定性 | 解释型脚本，长时间运行偶发异常，出错时提示信息有限 | 编译型程序，模块化结构，异常统一记录到日志，长时间挂机更省心 |
| 可维护性 | 单文件脚本，改动全靠手写，容易改出新问题 | 源码按功能拆分为 Models / Services 等模块，类型安全，便于持续修 bug 和加功能 |

**一句话总结**：老版本胜在体积小、源码轻；新版本胜在开箱即用、界面清晰、热键与更新更省心，后续维护和加功能也更容易。功能上两者完全一致，建议直接用新版本。

## 下载与运行

1. 到本仓库 \*\*Releases\*\* 页面下载最新版 \`Nightforge.exe\`（单文件，约 67 MB，Windows x64）。
2. 双击运行即可，无需安装、无需 .NET 运行时。
3. 配置保存在程序同目录的 \`config.ini\`，从旧版 AutoHotkey 版本迁移时，把旧的 \`config.ini\` 放到程序旁边即可直接复用。

## 更新方式

- 程序启动 3 秒后会\*\*静默联网检查\*\*是否有新版本，之后每 6 小时检查一次；
- 发现新版本会弹出「幻夜工坊 有新版本可以更新」窗口，显示当前版本、最新版本与更新内容，点「前往 GitHub 更新」即跳转到本仓库 Releases 页面下载；
- 可点界面上的「检查更新」手动检查，或用「启动时自动检查更新」开关控制；
- 弹窗内勾选「本版本不再提示」，可跳过该版本的提醒。

版本号来源：仓库根目录的 \`version.json\`（主通道，改一行就能推送更新通知）；若读取失败会退回 GitHub Releases 接口作为备用通道。
